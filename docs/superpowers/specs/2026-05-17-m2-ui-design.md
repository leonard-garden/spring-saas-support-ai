## React Component Tree

```
KbPage
├── page header (flex justify-between)
│   ├── h1 "Knowledge Base" + subtitle
│   └── <Button variant="primary"> + Upload Document   (ADMIN only)
├── DocumentSection
│   ├── <Card> with <Table> (shadcn)
│   │   └── DocumentRow (× N)
│   │       ├── <Badge> status — PENDING | PROCESSING | READY | FAILED
│   │       ├── useStatusPoller(docId)   // polls GET /kb/documents/{id} every 3s if PROCESSING
│   │       ├── error message row (colspan, bg-red-50) if FAILED
│   │       └── <Button variant="destructive"> Delete  (ADMIN, disabled if PROCESSING)
│   └── <EmptyState>  (no documents)
├── <UploadModal>  (Dialog — shadcn)
│   ├── FileDropzone   (drag & drop + browse)
│   ├── FileValidator  (client-side: type + size ≤ 10MB)
│   └── ProgressIndicator  (upload %)
└── SearchSection  (only rendered when readyCount ≥ 1)
    ├── search Input + Button
    ├── SearchResultList
    │   └── SearchResultItem  (content + score + source doc)
    └── EmptySearchState  ("No results for this query")
```

## State Management

| State | Where | Notes |
|---|---|---|
| `documents[]` | React Query (`useDocuments`) | Refetched on upload/delete |
| Polling active | `useStatusPoller` hook | Polls every 3s, stops on READY/FAILED |
| Upload modal open | local `useState` | |
| Upload progress | local `useState` | From `XMLHttpRequest.upload.onprogress` |
| Search query + results | local `useState` | Not persisted across page loads |

## Accessibility & Edge Cases

- Delete confirmation: inline confirm pattern (button changes to "Are you sure? [Confirm]") — no extra modal
- MEMBER role: Upload button and Delete button are hidden (not just disabled)
- Search panel hidden if `readyCount === 0` (no point searching empty KB)
- Max documents: no hard limit in M2; pagination deferred to M4+
- Failed document error message truncated at 120 chars in the row; full message available on hover (tooltip)
